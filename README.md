# Comprehensive-Input-Test 1

CI Language Lab. Learn by comprehensible input: sound before sight, pictures, chunks, stories.

**Repository:** https://github.com/ProCodingLegend/Comprehensive-Input-Test-1

This repo is the GitHub home for the CI Language Lab app (not velvet-mist-juniper-delta, not star-leaf-slate-apple).

## Run

```bash
git clone https://github.com/ProCodingLegend/Comprehensive-Input-Test-1.git
cd Comprehensive-Input-Test-1
npm install
npm run dev
```

## Course index (wired in `src/routes/lab.tsx`)

Greek, German, Spanish, Italian, Russian, French, Portuguese each list **18 units × 64 lessons**.

Look for the banner: `Full curriculum v3`.

## Pedagogy

Sound over sight. i+1. Pictures and TPR. Chunks. No translation drills as the primary mode.
